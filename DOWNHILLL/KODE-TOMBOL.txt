 Berlaku untuk USA (SCUS-97177) dan EROPA (SLES-52202)
 Paket: DOWNHILLL
========================================================================

CARA PAKAI
----------
1. Kode dimasukkan saat sudah masuk gameplay (bukan di menu utama).
2. Masukkan urutan tombol dengan CEPAT. Kalau terlalu lambat, kode gagal.
3. Kode "Unlock Code" WAJIB dimasukkan lebih dulu sebelum kode lain.
   Setelah Unlock Code berhasil, baru masukkan kode yang diinginkan.
4. Efek kode tombol biasanya langsung aktif. Sebagian kode hanya berlaku
   untuk sesi bermain saat itu, jadi masukkan ulang kalau game di-reset.
5. Kode tombol ini tidak perlu file .pnach dan tidak butuh cheat emulator.

CATATAN
-------
- "Unlock Everything" membuka item, level, video, music, editor, dan rider
  bonus. Kalau satu versi tidak berhasil, coba versi satunya.
- Kode tombol tidak bisa dipakai saat pause, saat loading, atau di menu.
- Kalau kode tidak bereaksi, ulangi dari Unlock Code. Pastikan tidak ada
  tombol lain yang ikut tertekan dan jangan memakai analog saat mengetik.
- Sumber urutan tombol: psxdatacenter.com (halaman SLES-52202) dan arsip
  kode komunitas Downhill Domination.
